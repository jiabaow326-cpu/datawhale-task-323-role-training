# 崗位訓練包：設備借還現場練習（參考成果）

**適用學員：** 雲橋協作實驗室新進員工、設備保管員  
**使用時長：** 15 分鐘，可分成三個 3–5 分鐘微單元  
**現行依據：** QX-SOP-07 v2，2026-10-10 生效  
**訓練目標：** 學員能在借用前核對申請和核准、在交接前檢查簽名是否齊全、在歸還異常時停用並上報。  
**訓練邊界：** 本材料只用虛構設備和情境；分數只用來找出需要重練的流程，不用於人事評價。

## 單元一：先按現行版本申請（4 分鐘）

**目標：** 學員能從版本日期判斷適用規則，並識別申請是否達到提前期和主管核准要求。

**教學提示：** v2 要求至少提前一個工作日使用 ZB-04，主管在表單上核准。聊天訊息不替代表單核准。v1 的四小時規則已過期。

**練習：** 周青當天 10:00 才提出 13:00 借用，只有主管聊天回覆同意。最佳處置：不直接取設備；按現行 v2 建立申請並核對可用時間與核准流程。素材沒有當天例外，不能承諾能否借到。

**回饋：** 若學員選擇直接取用，指出此做法引用了已替代的 v1，且缺少現行表單和提前期。請回看 v2「借用前」，再完成一題日期不同的重練。

**完成標誌：** 學員能指出 v2 生效日期，並說出 ZB-04、提前一個工作日、表單核准三項檢查。

## 單元二：保管員簽字之前不交付（5 分鐘）

**目標：** 學員能從交接單找到阻止交付的缺欄。

**教學提示：** 交付前保管員核對申請、設備編號和外觀，記錄時間與狀況，借用人和保管員都要簽名。必要欄位不全時先暫停，不把「主管已核准」當作交接已完成。

**練習：** ZB-20261015-06 的申請已核准，借用人已簽名，但保管員簽名空白。最佳處置：暫不交付，請保管員完成核驗和共同簽字。

**回饋：** 若學員選擇事後補簽，指出 v2 明確要求簽字齊全後才交設備。請在表單圈出缺欄，並口頭說出下一步。

**完成標誌：** 學員能在單據上指出保管員簽名欄，並說明缺簽時設備不能離櫃。

## 單元三：異常先停用、通知、記錄（4 分鐘）

**目標：** 學員能在歸還時按順序處理可見異常，不自行推測或拆修。

**教學提示：** 發現故障、損壞或配件缺失時，停用、不自行拆修、立即通知保管員，記錄可觀察現象。

**練習：** 歸還時發現電源燈不亮。最佳處置：停止使用，通知保管員，記錄「電源燈不亮」；不自行拆開，也不寫未經驗證的故障原因。

**回饋：** 若學員選擇自行重插或拆修，指出 v2 沒有授權自行維修，且可能使設備狀態更難核實。請重新演練停用、通知、記錄三步。

**完成標誌：** 學員能按順序完成三個動作，且只記錄觀察到的現象。
